# Bone Fracture Detection

Fine-tuned YOLOv12-nano object detector for fracture localization on musculoskeletal
X-rays, trained on the [FracAtlas](https://www.nature.com/articles/s41597-023-02432-4)
dataset. Upload an X-ray to see predicted fracture regions with confidence scores.

Full training/eval code: https://github.com/bhuvanagopalam/Bone-Fracture-Detection

For research/demo purposes only — not a medical diagnostic tool.
